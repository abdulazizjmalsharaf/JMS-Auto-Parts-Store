Build a complete, responsive e-commerce website for an online store selling car spare parts. The site must be BILINGUAL (Arabic + English) with a language switcher, support DARK and LIGHT MODE with a toggle, and be VERY EASY TO USE for everyone, including non-technical users.

## 1. The Shop
- Store name: JMS
- What we sell: car spare parts (filters, brake pads, batteries, oils, spark plugs, lights, etc.) for American, Japanese, Chinese, and German cars
- Target customers: car enthusiasts and everyday car owners
- Value proposition: prices lower than the market, with high quality
- Slogan:
  - Arabic: "قطعة صح.. بسعر صح"
  - English: "Right Part. Right Price."

## 2. Brand Identity
- Logo: text logo "JMS" in bold Oswald font, with a small gear/wrench icon integrated into the letter "J" or "S". Orange accent.
- Colors (CSS variables / Tailwind theme tokens):
  - Light mode: background #F4F5F7, cards #FFFFFF, text #111827, secondary text #6B7280
  - Dark mode: background #0B0F17, cards #161C28, text #F3F4F6, secondary text #9CA3AF, borders #263041
  - Accent (both modes): #FF6B00 orange for buttons/CTAs, hover #E65F00
- Fonts: Cairo (Arabic, 400/600/700) + Oswald (logo and prices) + Inter (English body). Load from Google Fonts.
- Brand personality: Strong, Trustworthy, Practical.
  Tone of voice: direct, friendly, confident, like a knowledgeable mechanic friend. Short sentences, no fluff.
- Visual style: dark hero section, bold typography, rounded cards (12px), subtle shadows, clean icons.

## 3. Language & Theme System
- Language switcher in the navbar (AR | EN).
- Arabic = RTL, English = LTR. Switch dir and lang on <html> dynamically; spacing, icons, arrows, drawer direction, and alignment must flip correctly.
- All text from a translations file (ar / en), including products, categories, buttons, messages, footer. No hardcoded text.
- Dark/Light toggle (sun/moon icon). Default to system preference (prefers-color-scheme).
- Save language and theme in localStorage and restore on reload.
- Smooth 0.3s transition when switching theme.

## 4. Car Origins & Brands (IMPORTANT)
Organize the store by car origin, with 4 main sections. Each origin has its own card/tab with a flag/icon, and clicking it filters the products:

1. American / أمريكي: Chevrolet, Ford, GMC, Dodge, Jeep, Cadillac
2. Japanese / ياباني: Toyota, Nissan, Honda, Mazda, Mitsubishi, Lexus
3. Chinese / صيني: Geely, Chery, MG, Changan, Haval, BYD
4. German / ألماني: Mercedes-Benz, BMW, Audi, Volkswagen, Porsche

- Home page shows 4 large origin cards right under the hero.
- Clicking an origin shows its brands; clicking a brand shows its parts.
- Filter sidebar includes: Origin → Brand → Category → Price range.
- Each product has: origin, brand, compatible models, and years.
- Sample products must cover all 4 origins (at least 4 products per origin, so 16+ products total).
- Product cards show a small origin badge (e.g., "🇯🇵 Japanese").

## 5. Website Design
- Home page with sticky navigation (Home, Products, Brands, Offers, Contact) + search bar + language switcher + theme toggle + favorites icon + cart icon with counter
- Hero: big headline with slogan, subtext ("جودة عالية بأسعار أقل من السوق" / "High quality at prices below the market"), orange CTA ("تسوّق الآن" / "Shop Now")
- Trust bar: Original quality / Best price / Fast delivery / Warranty
- Product cards: image, name, car compatibility, origin badge, price, old price crossed out, discount badge, Favorite (heart), Add to Cart
- Footer: contact, social links, payment methods

## 6. Interactions (all must work)
1. Hover: card lifts with shadow, image zooms slightly, "Quick View" button appears
2. Add to Cart: button animates, cart counter bounces, side drawer slides in (right in LTR, left in RTL) with items, quantities, total
3. Live Search: instant results dropdown as the user types (both languages)
4. Favorite: heart toggles with animation, saved in localStorage
5. Filters (origin/brand/category/price) update products instantly with a smooth transition

## 7. Customer Journey
Enter -> Explore -> Choose -> Interact -> Get a response
- Clear navigation and a clear CTA on every section
- After adding to cart: success toast + clear Checkout button ("إتمام الطلب" / "Checkout")

## 8. Ease of Use
- "Find your part" quick selector under the hero: Origin → Brand → Model → Year, then show compatible parts.
- Maximum 3 clicks from landing to checkout.
- Large, clear buttons (min 44px touch target), readable font sizes (min 16px body), high contrast in both modes.
- Mobile: bottom navigation bar (Home, Categories, Search, Cart, Favorites).
- Search bar always visible, with suggestions and a helpful "no results" message.
- Clear empty states (empty cart, no favorites) with a button back to shopping.
- Cart: quantity +/- buttons, remove button, always-visible total, sticky Checkout button.
- Simple one-page checkout: name, phone, city, address, cash on delivery, order summary, success confirmation screen.
- Loading skeletons instead of blank screens.
- Clear feedback for every action (toasts, button states, animations) in the current language.
- Floating WhatsApp button for quick help.
- Accessibility: alt text, keyboard navigation, visible focus states, aria-labels on icon buttons.
- Back-to-top button and breadcrumbs on inner pages.

## Tech
- React + Tailwind CSS (use dark: variants and logical properties ms-/me-/ps-/pe- instead of left/right)
- Clean, organized code: separate files for translations, theme context, language context, and data (origins, brands, products)
